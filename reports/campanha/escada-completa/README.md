# Campanha com sorteio da escada COMPLETA — superseded

Estes CSVs sortearam a condição de ruído entre as 17 da escada inteira
(degrau 0 mais degraus 1–4 × σ ∈ {1,3,5,10}). A campanha passou a usar **só o
maior ruído** (σ = 10, degraus 1–4), então eles não entram no relatório.

Ficam aqui porque são dados válidos, não lixo: são a leitura sob **regime
aleatório de ruído**, que é uma pergunta diferente de "o que acontece no pior σ".
As corridas estão incompletas (a campanha foi interrompida) — o `-episodios.csv`
diz exatamente quais condições cada episódio viu.

Não misture com os de σ=10: o sorteio depende do TAMANHO da escada, então o
episódio `s` recebe condições diferentes nos dois desenhos.
